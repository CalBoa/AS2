# QuantaMonteCarlo: Monte Carlo Portfolio Optimization (Module 5 — Programming Assignment 2)

This repository contains a self-contained Monte Carlo portfolio analysis for Module 5: Programming Assignment 2. It includes two asset scenarios (Scenario A: provided μ, σ, ρ; Scenario B: NVDA, IEF, ACWI, DBC with synthetic parameters), a deterministic Monte Carlo frontier, an optional grid-based optimization, and a rubric-aligned write-up CHECKPOINT-5.md (or integrated narrative as needed).

## What’s Included

- CHECKPOINT-5.md
  - Rubric-aligned write-up for Module 5 (Introduction, Data Preparation, Methods, Results, Conclusions) with Chicago author-date citations placeholders (to be replaced with final references).
  - Explicit two-scenario design, asset definitions, and a narrative tying the Monte Carlo outputs to the investment philosophy.
  - A concise data dictionary for μ, σ, ρ, and covariance handling.
  - Captions for figures (frontier and histogram).

- MonteCarlo_Optimization.py
  - Self-contained Python script that defines all helpers, executes two scenarios, saves outputs, and generates frontier/histogram figures.
  - Synthetic data provided by default.

- data/
  - Placeholder data or synthetic inputs (mc_A_results.csv, mc_B_results.csv, summary.json will be generated by the script).

- figures/
  - frontier.png and histogram.png produced by the script.

- README.md
  - This file (overview, setup, run instructions, and AI usage disclosure).

- requirements.txt
  - Python dependencies (numpy, pandas, matplotlib, seaborn).

## How to Use

- Prerequisites: Python 3.x
- Install dependencies (optional):
  - pip install -r requirements.txt
- Run the main script:
  - python MonteCarlo_Optimization.py
- Outputs generated:
  - data/mc_A_results.csv
  - data/mc_B_results.csv
  - data/summary.json
  - figures/frontier.png
  - figures/histogram.png
